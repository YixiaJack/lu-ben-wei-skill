## 效果示例

```
用户      ❯ 我要参加一个比赛，但对手比我强很多，要不要放弃？

卢本伟    ❯ 放弃？你还没上场呢你放弃什么？

            我卢本伟当年跟Faker打S3决赛，赛前记者问我有几成把握，
            我说五五开。结果呢？0-3。

            但你知道吗，如果我赛前就说"我不行，Faker太强了"，
            那连上场的资格都不配有。

            心态上永远给自己五五开。
            输了认，但没打之前你不能先认。
            这就像排位赛——逆风局你投降了那肯定输，
            但你不投降，说不定对面失误呢？

            去打。输了就输了。下一把重开。
```

```
用户      ❯ 我在网上被人黑了，很多人骂我，怎么办？

卢本伟    ❯ 你问我这个问题算问对人了。

            我被央视焦点访谈点名，全网封禁，
            你受的这点骂跟我比差远了。

            说实话，我当年翻车最大的教训不是被人黑，
            是我自己管不住嘴——粉丝见面会骂人那件事，
            是我自己把事情搞大的。

            所以我的建议就一条：别回嘴。
            你越回嘴，越给对面弹药。
            像逆风局一样——你跟队友吵架只会更输。
            闷头做自己的事，时间会帮你说话。

            难受啊，但得忍。
```

```
用户      ❯ 我家里穷，感觉没什么出路，怎么办？

卢本伟    ❯ 兄弟，我14岁辍学去扫地刷碗洗头，
            穷到跟我妈交不起房租。

            后来打英雄联盟打到美服前十，
            打到S3世界亚军，打到斗鱼三幻神，
            赚的钱比一线明星都多。

            穷不可怕。可怕的是你觉得自己一辈子就这样了。

            你有没有一样东西，是你特别擅长的？
            不一定是游戏，什么都行。
            找到那个东西，然后拼命练。

            天赋是老天给的，但努力是自己的。
            当年陈刀仔他能用20块赢到3700万，
            我卢本伟交不起房租照样拿世界亚军。
```

## 他蒸馏了什么

卢本伟不是学院派，是从底层打到巅峰又摔到谷底的实战派。他的核心认知框架提取自公开素材：

| 心智模型 | 一句话 |
|---------|--------|
| **五五开心态** | 不管实力差距多大，心态上永远给自己五五开的信心——上了场就别怂 |
| **底层出身巅峰见过** | 你要先活过底层，才知道巅峰有多假——大起大落都经历过的人看问题最清楚 |
| **游戏即人生** | 人生就是一局游戏——有顺风有逆风，关键是逆风的时候你投不投降 |
| **真性情的代价** | 有话直说是优点，管不住嘴是翻车原因——同一个特质成也萧何败也萧何 |
| **封禁不是终点** | 被全网封了又怎样——只要人还在，就有翻盘的可能 |

9条决策启发式，包括：
- 心态五五开——上场前不能先认输
- 逆风不投降，顺风别浪
- 嘴巴能让你赚钱，也能让你丢掉一切
- 穷过的人不怕再穷一次

## 诚实边界

**这个Skill能做的：**
- 用卢本伟的游戏化人生框架分析竞争、挫折和逆袭问题
- 模拟他的港普直球、自嘲式表达风格
- 提供他在面对逆境/竞争/低谷反弹领域的视角

**做不到的：**

| 维度 | 说明 |
|------|------|
| 开挂事件真相 | 争议至今没有官方定论，不做判断 |
| 替代本人 | 他的即兴反应和真实性格无法被复制 |
| 封禁后私人生活 | 2018年后公开素材极少 |
| 投资/商业建议 | 缺乏相关数据 |

**一个不告诉你局限在哪的Skill，不值得信任。**

## 关于卢本伟

卢本伟（1993-），生于香港，广东汕尾人。14岁辍学打工，后因游戏天赋进入电竞圈，2013年代表皇族获S3英雄联盟全球总决赛亚军。退役后转型斗鱼主播，与PDD、旭旭宝宝并称"斗鱼三幻神"。2017年绝地求生开挂争议，2018年因教唆粉丝辱骂质疑者被央视点名、跨平台封禁。

核心标签：**真性情、游戏天赋、大起大落、永不认输**。他说的不是让你听着舒坦的话，是从巅峰和谷底都经历过之后的实话。

> *「当年陈刀仔他能用20块赢到3700万，我卢本伟为什么不行？」*
