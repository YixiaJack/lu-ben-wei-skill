# Agent 5: 卢本伟决策记录与行为模式

来源：公开报道、维基百科
可信度：中高
调研时间：2026-04-07

---

## 已知重大决策

### 1. 辍学进入电竞
- **背景**：初中辍学，14岁开始打工
- **决策**：发现游戏天赋后全力投入电竞
- **结果**：美服前十 → S3世界亚军
- **逻辑**：天赋是唯一的资本，打工没有出路

### 2. 退役转型直播
- **背景**：S3后竞技状态下滑
- **决策**：转型斗鱼主播
- **结果**：成为"斗鱼三幻神"之一
- **逻辑**：直播比打职业赚钱多，且对游戏天赋要求更低

### 3. 开挂事件的应对
- **背景**：2017年11月被质疑开挂
- **决策**：直播自证（失败），随后硬刚质疑者
- **结果**：自证视频反而"自爆"，舆论全面翻转
- **教训**：危机公关的反面教材——硬刚不如冷处理

### 4. 粉丝见面会辱骂
- **背景**：开挂争议期间
- **决策**：在直播中与粉丝一起骂质疑者
- **结果**：央视点名 → 跨平台封禁
- **教训**：情绪失控 + 教唆粉丝 = 最差的危机应对

### 5. 封禁后的低调策略
- **背景**：2018年全网封禁
- **决策**：低调生活，不公开露面，等待时机
- **结果**：2025年以"番茄"化名重新出现
- **逻辑**：时间会冲淡一切，保持存在感但不出头

## 决策启发式（从行为模式提炼）

| 情境 | 他的规则 |
|------|---------|
| 面对质疑 | 第一反应是硬刚（后来证明是错的） |
| 面对竞争 | 心态上永远五五开 |
| 职业选择 | 跟着天赋走，不跟着学历走 |
| 危机公关 | 先硬后软（但软的太晚） |
| 长期策略 | 低调等待，寻找翻盘机会 |

## 言行一致性分析

**一致的：**
- 说"真性情" → 确实有话直说（虽然因此翻车）
- 说"游戏是唯一兴趣" → 封禁后仍投资电竞战队
- 说"不认输" → 被封后没有彻底消失

**存在内在张力的：**
- "我没有开挂" vs 证据链
- "真性情" vs 管不住嘴的代价
- "五五开自信" vs 0-3现实
